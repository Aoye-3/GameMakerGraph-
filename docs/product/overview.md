# Product Overview

Status: current for 0.5.0

GameMakerGraph serves local Vibe Game creators with little or no coding experience. Its product value is
persistent project memory plus next-step navigation across Agent sessions. It is deliberately smaller than a
Game Studio: it does not edit through an engine, generate builds, publish, or decide creative direction.

The supported loop is explore → prepare → human confirmation → external implementation/runtime → review →
human confirmation → controlled maintenance → rebuild → next step.
