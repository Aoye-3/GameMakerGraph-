# Confirmed Direction Record

Read this only after the user explicitly confirms a creative direction and asks to retain or hand it to
development. A discussion transcript is not a confirmed record.

Use the project's existing decision-document convention. If none exists, propose a Markdown record under
`docs/decisions/`; do not write it without authorization. Never overwrite a previous decision silently.

Record only:

- decision title, date, status, and relevant source revision;
- problem and evidence that matter;
- the direction explicitly confirmed by the user;
- rationale and accepted tradeoff;
- constraints, cuts, and deferred ideas;
- one observable success signal;
- unresolved questions that affect later work;
- an optional link to a superseded decision when replacement is explicit.

Keep one primary lens and at most one secondary lens. Link sources instead of copying the whole conversation.
The record confirms intent; it does not prove implementation or runtime quality.
